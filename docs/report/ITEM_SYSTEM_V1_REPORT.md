# 随机道具系统 V1 实施

## 已实现

- 配置集中在 src/shared/ItemConfig.ts。小心心恢复30%最大生命；狙击单发、最多持有10秒、蓄力0.3秒；溜冰鞋×1.8持续8秒；道具护盾免伤5秒，挡一次狙击即碎。
- 服务端 ItemSystem 负责固定开局人数档位、5秒首刷、加权抽样、数量上限与15秒地面存活时间。有限随机候选加网格回退，通过障碍/危险区/出生点/其他道具间距校验和可达网格检查。不改变地形生成器。
- 存活玩家接近自动拾取；确定性顺序原子移除。满血心心不消耗，同类增益刷新完整时长，主动武器替换会取消旧蓄力。
- 普攻输入临时由狙击接管，不添加新网络输入事件；服务器限制持枪转向速度，以权威朝向结算射线。只命中首个存活玩家，实体掩体和地图边界阻挡，不能连续穿透杀人。
- 道具护盾先免除全部生命伤害及毒伤，狙击命中时破盾。无道具护盾时狙击经现有 Damage Resolver 直接淘汰，产生正常伤害/死亡事件，由 MatchSession 记击杀，避免第二套计分。
- 复用既有 moveSpeed 和统一移动函数，溜冰鞋在技能速度修正后乘1.8，再与泥潭0.6合成；不影响冲刺速度、攻速或技能冷却。
- 死亡、退出/断线、结果、取消和试炼结束清空道具；无死亡掉落。重置创建新状态。尚未实现的小小花园入口不实例化战斗房间，因此不会生成战斗道具。
- 全量快照携带地面道具和各玩家临时状态；晚加入/原有重连接口恢复同一状态。事件只做表现，不让晚到事件重建物品。
- 客户端展示漂浮道具、拾取反馈、手持简笔狙击枪和瞄准线、射击轨迹、溜冰鞋轮子与短拖尾、护盾泡泡/破碎；HUD 一个主动武器槽及独立增益倒计时。保持当前浅色美术。

## 16人格兼容核对

已检查现有所有角色定义和 StatusEffects：没有真正无敌、反弹或不可命中的技能状态。

| 人格 | 与道具相关的既有行为 |
|---|---|
| ENTP | 破防/减益增伤不改变狙击单次淘汰规则 |
| INFP | 数值减伤与委屈能量保持原逻辑；数值减伤不等于道具免伤盾 |
| ESTJ | 延迟范围伤害由道具盾免除；狙击不改变预警时序 |
| ESTP | 冲刺不受溜冰鞋放大，常规移动与泥潭正常合成 |
| INTJ | 传送与印记保持原规则，不把标记当无敌 |
| INTP | 思考禁攻仍有效，不允许思考中绕过限制使用狙击 |
| ENTJ | 强制移动仍走现有移动模块 |
| INFJ | 标记/预判保持原逻辑 |
| ENFJ | 技能护盾为数值吸收，独立于道具盾 |
| ENFP | 随机增益与道具独立，既有速度倍率再乘溜冰鞋 |
| ISTJ | 攻速/流程叠层不增加狙击弹数 |
| ISFJ | 技能护盾值/减伤仍作用于普通伤害；道具盾单独计时 |
| ESFJ | 引导/范围伤害走统一伤害入口 |
| ISTP | 炮台伤害仍走统一伤害入口，无新增炮台道具槽 |
| ISFP | 淡出是视觉透明与强化一击，不是无敌，不改变命中资格 |
| ESFP | 范围/多段技能不额外消耗或增加狙击弹药 |

数值盾与减伤不是狙击免死：狙击会消耗既有数值吸收后淘汰；明确免除狙击的是道具盾。既有技能键、状态时间与普通伤害映射不变。狙击不提供人格能量。

## 手工联机验收

用两个浏览器创建并加入同一房间，开局5秒后看首次刷新；走近道具自动拾取。检查心心满血不消耗、溜冰鞋与盾独立倒计时；拾取狙击后按原普攻键，双方都应看到0.3秒瞄准/射击。分别测试掩体遮挡、无盾淘汰、有道具盾无伤破盾，然后结算再来一局，确认没有跨局状态。
