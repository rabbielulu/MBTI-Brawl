# M5 原房间重赛验证报告

按 `MBTI_BRAWL_MULTIPLAYER_GAME_FLOW_V0.1.md` 第 23 节完成 M5，停在本阶段。

## 行为
- RESULT 页面增加「再来一局」，保留「返回主页」。首位在线玩家点击后，全体在线成员一起返回同一房间，无需重新连接或输入昵称。
- 保留玩家 ID、席位、昵称、人格和机器人；删除已断开 / 退出席位及恢复凭据。人格可在大厅点击自己的角色卡修改。
- 2 人及以上重新等待 30 秒，满员也保留 30 秒供换人格；不足 2 人等待，人数再次降到 1 时取消倒计时。原有 Enter 调试开局仍可用。
- 服务端使用上一局结算时间校验重赛请求；重复 / 同时点击不会重复创建比赛或推迟倒计时。开战前不能重赛。
- 每局使用全新 MatchSession / GameRoom，清除 HP、能量、冷却、死亡、名次、伤害、击杀、弹丸、区域、状态效果、炮台与胜者。新地图独立生成。客户端清理网络插值、特效、观战及结算，再接收下一局 welcome。
- 网络协议升级为 11，需要重启 Host 并刷新客户端。

## 手动验收
