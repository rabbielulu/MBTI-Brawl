# VFX Playground V1

按已确认方案实现，入口 /vfx-playground.html。新增ArtConfig、ArenaFloor、ParticlePool、BurstVfx、ActorView、VfxPlayground、playground.css与独立HTML，Vite新增入口。复用CharacterFace，无新增渲染依赖，不修改正式main.ts、server、规则、地形或网络同步。

## 完成内容

- 缓存深紫蓝低对比几何地面、2.5D障碍顶/侧面与接触阴影，静态泥潭/毒区提供可读性对照。仅参数变化时重建地面。
- 0.9秒聚拢蓄力→短暂亮核/十字闪光→有限冲击波、地面光晕、粒子阻尼消散。默认粒子寿命1.5秒，最大16个并发技能。
- 当前火柴人面容、呼吸、施法压缩、波抵达时受击闪白/形变与视觉击退；不修改碰撞、HP或权威位置。全部16人格动作与胜利页不属于本次首轮。
- 实时颜色/光强/地面与波参数，数量/方向/角度/速度/生命/重力/大小/透明度在发射时采用配置。高/中/低硬预算512/256/96；固定粒子槽复用。WebGL ADD辉光，无Bloom，Canvas ALPHA回退。
- 暂停/重播/清空/默认参数、自动循环、8/16次并发演示、FPS/平均及P95帧时/活跃及峰值粒子/丢弃数/对象数。页面后台时清理旧效果，系统减少动态效果时降低粒子/闪光并关闭震屏及初始循环。

## 验证

TypeScript和Vite build通过。tests/vfx-pool.ts覆盖预算压缩、满池、生命周期、清空、回收、零预算、无效dt和30/120Hz阻尼轨迹，1000次发射后容量固定。

本机IAB浏览器1440×1000，WebGL单发约60FPS、P95约16.8ms；16次并发观测512/512粒子、丢弃640、场景对象8、约60FPS/P95约16.8ms；低档16次并发96/96且丢弃多余装饰粒子。地面密度键盘调节到24与薄荷配色参数联动成功。Canvas模式完成8次并发周期启动，无warning/error；不以此声称Windows/Electron验收完成。上述是本机短时采样，不是目标PC的长时间性能保证。
