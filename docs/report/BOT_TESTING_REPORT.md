# 多人房间机器人测试功能

## 使用

进入多人大厅，每按一次 **N** 添加一个机器人，也可点击「添加机器人 · N」。不需要另开浏览器。机器人使用随机的 ENTP / INFP / ESTJ / ESTP 与唯一内部 ID，昵称为机器人01等，卡片标注「自动对战机器人」。

机器人占用正常席位。一位真人最多添加七个机器人；两人起 30 秒倒计时、满房缩短至最多 5 秒，接原有 3 秒开场与 2 秒出生保护。开战后不能补人，N 会给出明确提示。输入框 / 设置 / 长按重复 / Ctrl、Cmd、Alt 组合键不会误添加。

## 实现

- `server/bots/BotController.ts`：服务端基础 AI，约 6Hz 决策；选择最近存活对手，近战接近、远程保持距离 / 侧移；按地图掩体构造网格路径，避免直接卡在墙上。
- AI 通过现有 `GameRoom.input` 发普通移动 / 瞄准 / 攻击指令，经过相同的参数验证、出生保护、技能冷却、能量、碰撞和伤害结算。不直接写 HP、不赋予额外伤害或瞬移。
- 四个人格使用自己的普攻、技能和大招；死亡后停止输入，正常计入名次和冠军。存活机器人可作为 M3 观战目标。
- `LobbyRoom` 增加 bot 标识、随机人格和正常席位；`MatchSession` 持有 AI，终局停止模拟。
- `room:addBot` 绑定当前连接所属房间，有原有限频与满房 / 阶段验证。客户端不能指定其他房间，也不能把自己的身份伪造成 bot。
- 机器人没有浏览器 Socket 连接。取消 / 清理检查排除机器人，最后一位真人离开时销毁房间，避免无人房间持续运行。
- 客户端增加 N 快捷键、可点击入口、加入反馈与 bot 标识。

协议升级至 **v8**，需要重启旧 Host 并刷新页面。当前本机 Host 已重启；代码未自动推送 GitHub 或更新公司电脑。

## 验证

执行并通过：

- TypeScript 类型检查、Vite 生产构建。
- `tests/bots.ts`：添加、人数 / 昵称唯一、满房、阶段锁、保护、真人退出清理；四人格分别绕过掩体后造成实际伤害；死亡停止指令；快捷键防误触。
- `tests/bots-network.ts`：真实 Socket.IO 一真人加七机器人、身份不变、房间隔离、自动开局和实际伤害、开局 / 满房拒绝、真人断线销毁房间。
- `tests/match.ts`、`tests/match-network.ts`、`tests/spectator.ts`、`tests/lobby-network.ts`：原比赛、恢复、名次、冠军、观战零输入及大厅流程回归。
- 浏览器实际按 N 添加首个机器人，连续按 N 补齐七个；界面显示八席、5 秒倒计时、机器人标识与成功提示。无需辅助脚本即可进入比赛，并产生机器人冠军。
- 开战后 N 提示下一局大厅添加，退出返回首页；health 确认 lobbyRooms / lobbyPlayers 都为 0。该浏览器测试未捕获 error 日志。

## 运行测试

```sh
npm run build
npm run test:bots
npm run test:match
npm run test:spectator
```

## 限制

基础 AI 用于测试房间、战斗和观战，不是高水平或可调难度的对手。机器人和真人仍共用当前 8 人原型；没有比赛中途补人、删除单个机器人或持久化功能。Phaser 构建体积提示仍存在。
