## 状态与规则

`LOBBY → COUNTDOWN（3 秒）→ PLAYING → WINNER / CANCELLED`。

服务器给出统一 startAt / serverStartTimestamp；客户端仅显示时间，不裁决开始。开局后的 2 秒允许移动 / 瞄准，禁止普攻、技能、大招和受到伤害。服务端和客户端均有输入保护，保护期不会消耗技能冷却或大招能量。

每局默认 8 席，允许 2–8 人开局，人数规则沿用 M1。各房间独立场地、玩家、弹丸、技能区域和事件，模拟 30Hz、快照目标 20Hz。出生点避开墙体并保持至少 100 世界单位间距；配置容量保留未来扩展接口，未实现 16 人正式模式。

HP 归零后立即禁用行动，记录击杀者、淘汰原因和名次。首次淘汰为总人数名次，其后递减；退出 / 断线淘汰不赠送击杀。击杀数、实际造成伤害和胜负独立统计。最后存活者为第 1 名；最后双方同 tick 致命伤可进入无冠军的平局。终局停止模拟和输入，不自动重开。

主动退出立即淘汰，保留本局名次记录；断线玩家停掉移动输入，在其他连接仍存在的情况下保留约 10 秒席位，可凭该连接收到的私有随机 token 恢复原身份。不能只靠玩家 ID 冒领席位；客户端恢复时保留输入序号。超时记录 disconnect；所有连接消失则取消，无冠军、无结果写入。无人房间销毁。

## UI 与操作

沿用 PC 的 WASD / 鼠标 / 左键普攻 / 右键技能 / 空格大招，以及现有移动端双摇杆和技能按钮。顶部只集中显示简洁人格头像，自己高亮，淘汰灰色骷髅；本人生命 / 能量保留 HUD，场地内其他人的 HP 数字收起。

开场显示大号 3 / 2 / 1；保护期文字与光圈可见。死亡显示「你被淘汰了 · 第 N 名 · 击杀者」，最后存活者显示明确身份。正式比赛隐藏训练重置按钮，服务端大厅命名空间也不接受 resetTraining。退出本局返回主页。
