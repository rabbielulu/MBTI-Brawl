# 冠军页动画 · Figma 39:229

采用 Figma 人物切图 congrats.png 和 crown.svg。冠军保留获胜者人格颜色、道具、MBTI 与昵称；删除可见的“MBTI 之王”和旧随机对白。新对白为“可把你厉害坏了”。

时间轴：0–800ms 人物从右侧飞入；800–1100ms 对白显现、手部蓄势；1100–2250ms 皇冠从手指位置沿弧线飞到冠军头顶；2250–2550ms 落冠缓冲；2550ms 开始有限彩纸动画；6400ms 由服务器切入战绩页。

皇冠起终点根据 DOM 实际手部和头顶位置测量，视口变化时重算；后台恢复按服务器 endedAt 同步；离开页面取消动画并释放监听。系统减少动态效果时直接显示最终加冠画面。

验证：TypeScript 和 Vite build 通过；tests/results.ts（轨迹起终点、时序关系、冻结结果和服务端阶段边界）及 tests/rematch.ts 通过。真实双人房间连续三局，桌面 1440×1024 与手机 390×844 验证落冠后撒花，自动战绩切换、再来一局及退出；浏览器错误日志为空。

旧 tests/match-network.ts 在冠军阶段之前的开局等待仍不稳定：两次未在 6500ms 内收到 welcome，另一次加长等待后已进入 PLAYING 而非断言的 COUNTDOWN。未修改该开局逻辑，也未宣称此测试通过。本次仅将其结算等待从5500ms调整为8000ms以匹配新庆祝时长。

协议升级为14；本机 Host 已重启，其他客户端需刷新。截图见 artifacts/champion/desktop.png、mobile.png。
