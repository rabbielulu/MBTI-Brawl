# UI Visual Style Guide V2 实施

新增 src/client/ui/visual-v2.css，由 src/main.ts 引入，统一所有产品界面的设计 token 和表现。采用 #1E203E 深靛蓝、#302A55 深紫、#FFF9EF 奶油白、#D9C8FF 薰衣草紫、#FFDB77 柔黄；2px 深描边、圆角和统一方向的偏移阴影。以轻微点状纹理提供纸感，按钮只在 hover/pressed 时短促反馈，尊重减少动态效果设置。

覆盖欢迎页、角色创建、玩法菜单、多人入口与房间、角色图鉴/档案、排行榜、设置弹窗、局内 HUD 和结算。角色卡使用已有阵营色混合粉彩，保持16人格与火柴人造型；空房间使用深紫虚线槽位。修正排行榜空状态和冠军身份文字在新底色下的对比度。

mingming 图片文件、图片引用、位置、大小、朝向以及冠军颁奖动画逻辑均未修改。没有改动信息架构、布局结构、交互逻辑、战斗、地形、网络或服务器。样式不新增独立功能或装饰动画。

TypeScript、Vite 构建通过。浏览器逐页检查欢迎、创建、菜单、房间、图鉴、档案和排行榜，截图存于 artifacts/visual-v2。原浅色界面截图见 artifacts/lobby-avatar。暂无 Windows/Electron 或真实手机性能结论。未推送 GitHub。
