视觉：Figma 文件 oKybAbnv1MfebanRgnVlD4 的 2:160 背景素材落地在 public/garden/meadow.png；Figma 的灰色占位人物和占位人格卡由项目已有的人格外观及身份卡替换。背景装饰不提供交互。侧躺使用身体旋转和撑头/叉腰手臂姿态。

范围说明：第一版为同服务器公共花园，不包含单独花园房间号、触屏操作、断线自动重连、聊天、NPC 或奖励。客户端对权威快照插值，尚未加入本地移动预测。30 人容量由规则测试验证，未执行 30 台真实设备并发压测。网络断开后提示返回重进。

## 测试机器人补充

花园顶部「＋ 测试机器人」为每位玩家添加一组 3 个机器人（站立/挥手、缓慢散步、侧躺），可用于牵手、跟随、叠罗汉和踩踏测试。机器人不主动牵人或挣脱；带着叠罗汉时暂停自主散步。重复点击不叠加，受 30 人总容量限制。可手动移除自己的机器人，玩家离开时自动清理。此为按需调试工具。`tests/garden-bots.ts` 和浏览器添加/去重/移除验证通过。


## 交互简化更新

以本次用户要求覆盖初版文档：已删除叠罗汉状态、站头判定、吸附、带塔移动/跳跃、相关参数和展示。普通跳跃保留，落地不会附着其他玩家。牵手取消时机浮标，改为点击附近的可交互玩家后显示 🤝 按钮，再点击按钮发送指定目标 ID；服务端检查距离、目标占用和链条环路。点空地或目标移出范围会取消选择。连续牵手及鼠标挣脱保留。规则测试更新覆盖指定目标、无效目标、距离、环路和不再站头。

## 坐下动作

新增 Z 键切换盘坐/起身，坐姿采用向两侧展开的膝盖、内折的小腿及自然垂下的双臂。坐下时身体平滑降低，并同步给其他玩家；保持坐姿不会自动进入侧躺，仍可按 E 挥手。移动、跳跃或被牵起后起身；空中不触发坐下。规则测试覆盖切换、长时间保持、挥手与移动/跳跃退出。

## Q 键松手

新增 Q 结束牵手：Follower 断开前方连接并保留身后的队伍，Leader 松开第一位跟随者；独立玩家按 Q 不产生动作。服务端确认断开并清理挣脱进度，保留甩鼠标挣脱。底部操作提示与帮助已更新，规则测试覆盖领队、中间玩家、队尾与未牵手情况。


## 举起与投掷

选中附近玩家后新增 🙌 投掷按钮：先举到头顶，携带者双臂上举、被举者横躺；移动鼠标瞄准，左键触发抛物线飞行和空中旋转。服务端同步 carriedBy / carrying / thrown / flightTime / vx / vy，四面场景边界按恢复系数反射水平速度，落地后侧躺并保留 0.6 秒落地缓冲，之后移动或跳跃起身。配置统一放在 GardenConfig。飞行无伤害，不重新引入站头机制。

举起会解除双方已有牵手连接，不能抓自己、超距离目标、正在被举/飞行的人或另一位举人者；Q 可放下或主动下来。携带者断线会释放被举者并自然落地。机器人在被举/飞行/落地缓冲期间暂停自主动作。

新增 tests/garden-throw.ts，覆盖目标验证、关系清理、携带移动、四边及角落反弹、落地姿态/起身、Q 放下及断线；tests/garden-throw-network.ts 验证两个客户端同步看到举起、飞行和落地。Chrome 实测目标菜单→举起→鼠标左键投掷→落地侧躺通过。

### 落地动画平滑修正

取消投掷中的持续翻转，举起、飞行与落地沿用同一侧躺肢体姿态，空中只保留 ±3° 轻摆。所有状态统一使用身体中心作为旋转原点，姿态角度和贴地偏移按帧时间平滑过渡，移除重复的 CSS transform 过渡。独立花园浏览器逐帧采样：飞行角度跨度约 2.77°，落地切换帧角度变化约 0.073°，旋转中心始终一致；构建与类型检查通过。
