# M3 · Spectator 验收记录

依据 `MBTI_BRAWL_MULTIPLAYER_GAME_FLOW_V0.1.md` 的 Death / Spectator / Exit 与 M3 阶段要求，完成本阶段后停止，未进入 M4。

## 改动

- 新增 `src/client/spectator/SpectatorController.ts`：独立的观战展示状态，处理死亡等待、立即 / 自动观战、稳定目标、循环切换和目标失效。
- `LobbyFlow.ts`：死亡界面「继续观战」与倒计时；观战目标、剩余人数、左右按钮；A / D、左右方向键；终局 / 退出清理。
- `lobby.css`：紧凑观战栏，触控按钮至少 48px，手机安全区、焦点和长昵称换行。观战时收起本人生命 / 能量及角色操作栏。
- `src/main.ts`：镜头跟随经过网络插值的存活目标，平滑移动并限制在地图内；死亡后收起摇杆与横屏提示，允许竖屏观战。
- `NetworkClient.ts`、`LobbyClient.ts`：在发送入口拦截死亡 / 非 PLAYING 状态的战斗包，包含 blur / resize / 清理输入的强制零输入包。
- 新增 `tests/spectator.ts`、扩展 `tests/match-network.ts`；新增 `npm run test:spectator`。
- README 与 `artifacts/spectator-m3/`：尺寸预览、正常协议辅助玩家脚本、截图。

没有改动服务端战斗裁决、房间协议或数据库，协议仍为 v7。

## 行为

1. 玩家死亡后立即禁用战斗操作，显示击杀者、名次、继续观战按钮与约 3 秒自动进入提示。
2. 可以立即进入；不点击则按服务端淘汰时间及校准时钟自动进入。此逻辑不修改 alive / winner。
3. 按席位顺序选择目标；A / D、左右方向键、屏幕按钮循环切换。相同昵称 / MBTI 通过唯一 ID 区分。
4. 目标在普通快照更新后保持不变，避免持续跳镜头。目标淘汰 / 退出后选择下一存活席位。
5. 优先观战在线存活玩家；若存活者全在断线宽限期，可查看其最后位置并标注离线。无有效目标则显示等待状态，按钮禁用。
6. 输入框、设置弹窗、组合快捷键与长按重复不触发切换。断线时停止切换；恢复原房间快照可保持观战状态。
7. WINNER / CANCELLED 收起观战栏。退出仍走原 room:leave，返回主页并清理目标；不提前实现 M4 庆祝结算或 M5 再战。

观战测试覆盖：

- 3 秒边界、立即进入、仍存活时禁止观战、新比赛 / 退出重置。
- 首尾循环、快照更新保留选择、目标死亡与离线后选择下一目标。
- 无目标、仅一个有效目标、终局、断线宽限期全部离线。
- A / D 和方向键、编辑输入 / 组合键 / 按键重复防误操作。

## 浏览器验收

使用普通协议辅助玩家进行真实移动与攻击，没有修改服务器 HP / alive 或注入浏览器游戏状态。

- 实际击杀玩家后观察到淘汰、名次、击杀者和自动观战提示，随后自动进入观战。
- 点击下一位、方向键与 A 键切换成功；当前目标主动退出，自动切到下一席位。
- 844×390 横屏和 390×844 竖屏 iframe CSS 视口无横向溢出。切换尺寸保留连接和目标，目标保持在镜头内；观战栏高度约 91px，未继承旧导航栏的满屏高度。
- 开启触屏后，死亡 / 观战时摇杆与横屏提示隐藏，竖屏可看比赛；左右按钮可操作。
- 比赛终局后切换控件隐藏，观战样式移除；退出返回首页，验收房间已释放。
- 「立即观战」的提前进入逻辑已做自动测试；浏览器验收以自动进入路径为主，未把未捕获的瞬时点击标为人工通过。

## 限制与记录

- 手机验收为真实 CSS 尺寸预览，不是真实 iOS / Android 设备测试。
- 内置浏览器 iframe 预览期间捕获过一条 `MutationObserver.observe` 的 Node 类型错误。项目源码及检查的 Phaser / Socket.IO 客户端源码未发现该调用，尚不能确定来源；观战与退出流程仍完成。桌面测试未捕获脚本错误，不将整轮宣称为零错误。
- 观战限本局已加入并被淘汰的玩家；没有开放比赛中途的新观众加入。
- 现有 M2 的内存房间、刷新离开与 Host 重启限制不变。
- 只完成 M3；下一阶段为 M4 Celebration & Result。

## 复现

```sh
npm run build
npm run test:spectator
npm run test:match
npm run start:lan
```

浏览器创建昵称「开场测试」的房间，然后在另一终端执行：

```sh
npx tsx artifacts/spectator-m3/preview-players.ts 房间号 180000
```

辅助玩家通过正常攻击淘汰该昵称，然后继续移动以观察镜头。辅助终端可输入 `drop 0` 让第一个目标退出，输入 `end` 释放全部辅助玩家。
