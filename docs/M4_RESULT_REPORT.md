# M4 · Celebration & Result 验收

依据 `MBTI_BRAWL_MULTIPLAYER_GAME_FLOW_V0.1.md` 第 20–22、36、38 节，以及继续 M4 的用户指令。完成后停止，未进入 M5 / M6。

## 完成内容

- 最后存活者先独立庆祝 **4 秒**：皇冠、举手胜利姿势、彩屑、人格 / 昵称与专属胜利台词。提供 reduced-motion 样式。
- 服务端统一 `WINNER → RESULT`，客户端不会根据本地倒计时猜测阶段。
- 战绩表按淘汰名次排序，显示人格 / 昵称、击杀、实际伤害、存活时间，前三名奖牌，本人高亮，机器人标识保留。
- 五类趣味称号由真实数据产生：杀疯了、人形核弹、你抓不到我、专业针对、全场最惨。正数并列共享，零数据不硬颁奖；没有数值奖励。
- 平局没有冠军 / 皇冠，显示握手和平局结算；取消比赛不生成结果或称号。
- 结算可返回主页。没有同房再战按钮、持久化、排行榜写入或伪造数据。

## 数据与权威

服务端记录实际伤害、承受伤害、位移、技能 / 大招次数及对同一目标的有效命中次数。位移来自实际位置差，包含冲刺 / 击退；存活从 match startAt 算起，死亡 / 退出时冻结，冠军截至结束时间，不含大厅和庆祝时间。

「专业针对」采用对同一目标的**有效命中次数**，包含区域技能脉冲；未把没有命中的发射行为伪装成已指定某个玩家的攻击。

结束时冻结包含身份的独立结果快照，冠军不因随后退出或断线而改变。普通房间快照与最终结果均深拷贝，客户端无法通过展示状态修改结算。终局停止战斗与机器人模拟；RESULT 房间最后一位真人离开后正常销毁。

## 浏览器验收

1. 使用 N 添加七个机器人，完成真实八人比赛。捕获皇冠 / 胜利姿势 / 彩屑与 ENTP 台词，随后进入八行战绩与五类实际称号。冠军、伤害和名次独立显示，实际结果不由 UI 生成。
2. 检查战绩表、本人高亮、并列承伤称号、滚动到称号区及返回主页。
3. 手机尺寸预览通过普通七连接在开局后主动退出完成受控比赛，捕获 ESTP 专属台词及 4 秒庆祝。确认零击杀 / 伤害保持 0，称号区显示无奖提示。
4. 390×844 竖屏、844×390 横屏均显示八行战绩，结算容器无横向溢出；竖屏表格使用局部横向滚动，允许纵向滚动和返回主页。
5. 本轮桌面与手机预览捕获的 error 日志为空；验收退出后释放房间。

手机验收为真实 iframe CSS 视口，不是真实 iOS / Android 触摸设备验收。reduced-motion 为样式实现，未单独做系统设置切换验收。

## 限制与下一阶段

- 没有数据库，结果只保存在本局内存，退出 / 重启后不提供历史战绩。
- 尚未实现 M5 同房再战或 M6 排行榜。
- 个别基础机器人对局可能持续周旋，没有强制比赛时限；手机尺寸验收因此改用普通连接主动退出的受控结束方式。未在 M4 中偷偷改变机器人战斗强度或服务器 HP。
