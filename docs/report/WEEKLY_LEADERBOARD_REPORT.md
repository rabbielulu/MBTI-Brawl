# 多人乱斗周榜

新增主界面周榜入口和独立榜单页，包含统计日期、名次、昵称、胜场、本人高亮、刷新、加载/空榜/失败状态。手机布局已验证。

仅服务端生成的多人乱斗冠军结果计分，每场唯一ID。试炼场、平局、机器人冠军、开战前结束不计入。记录在结算广播、退出清理及重赛前处理，避免冠军离开或切换重赛丢分；不可通过客户端提交胜场。北京时间周一00:00划周，胜场相同使用竞赛排名（1,1,3），展示前100名。目前按昵称（trim+NFC）累计，同名合并、改名分开，页面明确说明。无历史存档，更新后开始计分。

JSON版本化记录，写临时文件后原子替换，成功后更新内存；重启恢复去重索引。损坏数据启动报错而非覆盖。默认data/leaderboard.json，可用BRAWL_DATA_DIR指定持久目录，数据不进Git。测试服务port0默认仅内存；测试可显式传独立文件路径。

验证：TypeScript、Vite build通过；tests/leaderboard.ts覆盖北京时间周界、胜场排序、并列、周切换、排除规则、重启与重复记录、实际双人房间退出形成冠军及公开API。浏览器独立端口3001验证空榜→实际双人胜利→1胜，桌面1280×720和手机390×844，错误日志为空；测试数据与正式榜单隔离。截图artifacts/weekly-ranking/。
