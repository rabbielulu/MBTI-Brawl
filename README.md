# MBTI 大乱斗 · 16 Personalities Combat V0.2

Phaser 3 + TypeScript + Vite，Node.js + Socket.IO。当前完成 **M5 比赛、观战、结算与原房间重赛**：首页 → 选择人格 / 昵称 → 创建或加入房间 → 邀请 → 大厅倒计时 → 3 / 2 / 1 → 自由混战 → 淘汰名次 / 最后存活者获胜。每个房间使用独立的服务端战斗模拟。

当前可选 ENTP / INFP / ESTJ / ESTP，允许重复人格。既有单人训练与四人 LAN 对练保留，和新大厅独立。

## 启动

需要 Node.js 20.19+ 或 22.12+。首次 `npm install`，然后双击 `启动Host.command`，或：

```sh
npm run build
npm run start:lan
```

本机打开 `http://localhost:3000`，选择「多人乱斗」。服务器监听 `0.0.0.0:3000`，静态页面、战斗和大厅共用端口。开发模式 `npm run dev` 同时启动 Node 3000 与 Vite 5173；修改服务器代码后重启 Node。

**当前协议 v15，升级后先停止旧 Host 并重启，各设备刷新页面。** 快捷方式复用已有 Host 时仅更新前端构建。保持 Host 终端打开，Control+C 停止。

## 大厅试玩

1. 选择人格，输入 1–12 字符昵称。房间号留空可创建新房间。
2. 一人时等待；「邀请朋友」复制房间 URL，同一 LAN 的朋友打开后直接创建角色并加入该房间。
3. 本机 localhost 创建时，邀请链接优先使用 LAN IP。手机不能访问自己的 localhost；多网卡 / VPN 时核对 Host 终端显示的可达 IP。
4. 两人起 30 秒；退回一人取消计时，重新两人再计 30 秒。满房缩短至最多 5 秒。
5. 点击自己的 Slot 可修改人格和昵称；倒计时截止后锁定，显示统一的 3 / 2 / 1，进入比赛。前 2 秒可移动和瞄准，不能攻击或受到伤害。
6. 大厅退出释放席位；比赛主动退出立即淘汰且不赠送击杀，断线有约 10 秒恢复窗口。所有人断开则取消比赛。比赛开始后拒绝新玩家加入；Host 重启不保留房间。
7. 自动复制不可用时使用下方手动复制字段。手机支持纵向滚动和横竖屏布局。

## 机器人测试

进入多人大厅后，键盘每按一次 **N** 添加一个机器人；也可点击「🤖 添加机器人 · N」。机器人随机使用四个已开放人格，占一个正常席位，遵守大厅倒计时与最多 8 人的限制。自己一个人时最多添加 7 个；满房最多 5 秒后准备开局。

开局后机器人自动移动、绕过掩体、选择对手、普攻和释放技能 / 大招，遵守倒计时、冷却、HP、淘汰和冠军规则。最后一位真人退出 / 断开时清理整个测试房间。比赛开始后不允许补加，输入昵称或打开设置时 N 不会误触发。当前为测试用基础 AI，没有难度设置。

大厅人数至少 2 人（机器人也计入）时，按 **Enter** 跳过 30 秒 / 5 秒大厅等待，直接进入 3、2、1 开场；开战后不额外附加出生保护。输入框、设置弹窗和重复按键不会触发，也不能提前启动其他房间或重复创建比赛。

## 正式比赛与原战斗试玩

正式比赛：最后存活者获胜，按淘汰顺序确定名次，死亡后停止输入；顶部头像标识存活 / 淘汰与自己。比赛没有训练重置按钮，结束后通过「退出本局」回首页。淘汰后约 3 秒自动观战，也可点「继续观战」立即进入。镜头跟随存活玩家，A / D、左右方向键或屏幕按钮切换；目标淘汰 / 离线后自动换人。观战不发送战斗输入，终局收起切换栏。最后存活者先展示 6.4 秒飞入、抛冠与撒花庆祝，再进入战绩表（名次 / 击杀 / 伤害 / 存活时间）及数据驱动的趣味称号；平局无冠军，取消无结算。可点击「再来一局」返回原房间。


首页「单人试玩」进入原试验场表单。单机 ENTP 训练靶保持可用；选择「四人 LAN 对练 · 调试」可继续旧的四人格战斗测试。它不是新大厅的八人正式比赛。

PC：WASD、鼠标瞄准、左键普攻、右键技能、空格大招。手机：设置开启触屏、横屏，左摇杆移动、右摇杆松手攻击，技能按人格点击 / 拖动。能量满 100 可大招，击倒后可重置对练。

ENTP / INFP / ESTJ 普攻弹速恢复为 680 / 540 / 780，保留放大的 ENTP 弹丸文字；连续渲染时间轴减轻网络快照引起的弹丸跳动。Emoji / Typography / Geometry 共用渲染器，零新增 Sprite。每局按地形组合随机生成障碍、泥潭与毒区。

## 随机地形 MVP

每局由 Host 按种子生成 Open / Normal / Maze / Muddy / Toxic / Chaos 六种组合。外围均匀出生，安全半径 105；0–5 个障碍、0–2 个泥潭、0–2 个毒区，总预算最多 30。泥潭移速为 60%，毒区每秒造成最大生命值 5% 的环境伤害；离开立即停止。开局直接倒数 3 秒，之后可直接战斗。

试炼入口展开“地形调试”可指定种子、强制组合；固定种子时重置复现同图，留空时随机生成。游戏内 F3 显示种子、组合、预算、出生安全圈和碰撞边界。主要参数在 `src/shared/terrain/TerrainConfig.ts`。运行 `npm run test:terrain` 验证。协议 v15，升级需重启 Host、刷新各客户端。

## 本周胜场榜

主界面点击「排行榜 · 本周胜场」。多人乱斗真人冠军每局 +1，同胜场并列；试炼、平局、机器人获胜和开战前结束不计入。北京时间周一00:00自动切换统计区间，展示前100位。当前没有账号系统，按昵称累计：同名合并、改名后分开。历史比赛没有存档，因此从此功能上线后开始累计。

数据默认保存至 `data/leaderboard.json`（已加入Git忽略），临时文件写入后原子替换，比赛唯一ID防重复。可用 `BRAWL_DATA_DIR` 指定存储目录；公网托管需把这个目录放到持久磁盘，否则平台重新部署可能清空本地文件。API为 `GET /api/leaderboard/weekly`，测试运行 `npm run test:leaderboard`。

访问 `http://localhost:3000/vfx-playground.html`。深紫蓝几何地面、接触阴影、完整蓄力/爆发/消散、粒子/光晕/冲击波和受击闪白。右侧实时调节颜色、粒子方向/角度/数量/速度/大小/透明度/寿命/重力、波半径/速度、地面密度/对比度/阴影与震屏；可重播、暂停、清空、恢复默认及8/16次同时释放。面板可滚动。
