## 已接通流程

- 欢迎 → 创建角色 → 玩法菜单。人格与昵称保存到本机，确认后才进入玩法选择，不再提前创建多人房间。
- 左侧换人格 → 16 人格浏览 → 档案 → 确认 → 返回原入口。取消不更改人格；等待大厅内倒计时结束时仍服从服务端角色锁定。
- Mode 1：独立机器人试炼，可选 2 / 3 / 5 / 7 名机器人，最多仍为 8 人同场。支持 16 人格、场内更换、完整重置；机器人被击败不会生成正式比赛冠军结算。单人退出后房间及机器人清理。试炼复用正式服务端战斗系统，不复制战斗规则。
- Mode 2：先创建房间或输入房号加入，之后使用现有八人大厅、邀请、倒计时、观战、结算和重赛流程。开局后不能更换人格或使用试炼重置。
- Mode 3：小小花园入口显示“暂未开放”，没有开发场景、玩法或加入流程。
- 邀请链接：直接进入角色确认，确认后加入对应房间；不经过不必要的模式选择。
- 返回：场内退出回玩法菜单；结算的返回主页回欢迎页；试炼重置 / 换人格保留当前试炼席位。

## 结构与协议

- 新增 `CharacterCard.ts`：角色卡和技能详情为模式菜单、角色浏览与场内档案共用，数据来自原有角色配置。
- `LobbyFlow.ts` 增加欢迎、模式菜单、角色浏览、房间入口和试炼确认状态。
- `flow-structure.css` 提供响应式布局与 HUD 位置，保留全屏、设置、触屏与观战能力。
- `LobbyClient` / `LobbyProtocol` / `LobbyRoom` / `installLobby` 增加独立试炼创建、重置；`MatchSession` 使用 practice 标志复用模拟，正式多人胜负逻辑不变。
- 协议升级 **13**。Host 需要重启，所有客户端需要刷新。
